API

The same engine over HTTP · stateless · nothing stored
POST/api/scan
Multipart file (WAV), optional window, hop. Returns the verdict, risk, per-detector evidence, engine thresholds, PSD, spectrogram grid, waveform, window timeline and a capture-rate note.
curl -F file=@clip.wav -F window=1.0 \ http://127.0.0.1:8000/api/scan
POST/api/gate
Multipart file, action = routine | sensitive | critical, optional command. Returns allow, confirm or block with the reason.
curl -F file=@cmd.wav -F action=critical \ -F command="unlock the door" \ http://127.0.0.1:8000/api/gate
