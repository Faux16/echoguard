API

the same engine over HTTP — stateless, nothing stored

POST /api/scan

multipart: file (WAV), optional window, hop 
curl -F file=@clip.wav -F window=1.0 \
  http://127.0.0.1:8000/api/scan

Returns the verdict, risk, per-detector evidence, a PSD, a spectrogram grid, the waveform envelope, the window timeline and a capture-rate note.

POST /api/gate

multipart: file, action = routine | sensitive | critical, optional command 
curl -F file=@cmd.wav -F action=critical \
  -F command="unlock the door" \
  http://127.0.0.1:8000/api/gate

Returns allow / confirm / block with the reason and the full report.

Python

from echoguard import Pipeline, ConfirmationGate, ActionSensitivity
report = Pipeline().analyze_windows(samples, sample_rate).summary
result = ConfirmationGate().evaluate(samples, sample_rate, ActionSensitivity.CRITICAL)
